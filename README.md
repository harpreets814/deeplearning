# Deep Learning Projects

A collection of deep learning and machine learning projects implemented in Python using neural networks, recurrent neural networks, and practical predictive modeling techniques.

This repository contains implementations and experiments covering **RNNs, LSTMs, and customer churn prediction**, along with the required Python dependencies.

## 📂 Repository Structure

```text
deeplearning/
│
├── Churn_Project/
│   └── Customer churn prediction project
│
├── LSTM RNN/
│   └── LSTM-based recurrent neural network experiments
│
├── Rnn/
│   └── Recurrent Neural Network implementations and experiments
│
├── requirements.txt
├── .gitignore
└── README.md
```

## 🚀 Projects

### 1. Customer Churn Prediction

The `Churn_Project` directory contains a machine learning/deep learning project focused on predicting whether a customer is likely to leave a service.

**Key concepts:**

* Data preprocessing
* Feature engineering
* Categorical feature encoding
* Feature scaling
* Neural network modeling
* Model evaluation
* Binary classification

### 2. LSTM RNN

The `LSTM RNN` directory contains implementations and experiments using **Long Short-Term Memory (LSTM)** networks.

LSTMs are a type of recurrent neural network designed to learn dependencies in sequential data while addressing limitations of traditional RNNs.

**Concepts covered:**

* Recurrent Neural Networks
* LSTM architecture
* Sequential data
* Forward propagation
* Backpropagation Through Time
* Sequence prediction
* Model training and evaluation

### 3. RNN

The `Rnn` directory contains implementations and experiments with **Recurrent Neural Networks**.

**Concepts covered:**

* Recurrent connections
* Hidden states
* Sequential modeling
* Time-series/sequential data
* Training recurrent networks

## ⚙️ Installation

Clone the repository:

```bash
git clone git@github.com:harpreets814/deeplearning.git
cd deeplearning
```

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it on macOS/Linux:

```bash
source venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Projects

Navigate to the individual project directory and run the relevant Python script or Jupyter Notebook.

For example:

```bash
cd Churn_Project
```

or:

```bash
cd "LSTM RNN"
```

If the project uses a Jupyter Notebook:

```bash
jupyter notebook
```
